# סימולטור שחפים

סימולטור הדרכה לעבודה במערכת "שחפים" — אפליקציית דף אחד (HTML בודד, ללא תלויות
ובלי צורך בשרת), בעברית ובכיוון RTL. כל הנתונים מדומים ונוצרים בדפדפן; אין
חיבור למערכת אמיתית ואין שליחת מידע לשום מקום.

## כניסה לסימולטור

🔗 **https://MoAtPsyc.github.io/shachafim-simulator/**

## מה יש בפנים

- **איתור תלמידים וגיליון תלמיד** — פניות, הסכמות מדעת, ויתורי סודיות
- **עבודה מערכתית** — איתור מערכות וגיליון מערכת
- **טיפול קבוצתי** — ניהול הקבוצות שלי
- **יומן עבודה, המשימות שלי, אזור אישי**
- **מצב מדריך** — רצועת הדרכה עליונה לשימוש בהכשרות
- **חדר הכושר** — תרגול ותעודת גלישה בטוחה

## הפעלה מקומית

פתיחה ישירה של `index.html` בדפדפן מספיקה. לחלופין:

```sh
python3 -m http.server 8000
# ואז: http://localhost:8000
```

## פיתוח

הכול נמצא בקובץ `index.html` — מבנה, עיצוב ולוגיקה. עריכה של הקובץ ודחיפה
לענף `main` מעדכנת את האתר ב-GitHub Pages אוטומטית.
